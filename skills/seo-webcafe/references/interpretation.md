# 数据口径速查

引用任何数字时，带上这里的口径和时间。

## 关键词难度（`kd`）

- **哥飞版 KD**：0–100，综合前十结果的首页/内页结构、DR、流量、行为、域龄等信号；附中文判断原因与外链预算。
- 分档：<20 极易、20–40 容易、40–60 中等、60–80 困难、>80 极难（页面标签为准）。
- **不要和「预筛难度」比大小**：`ideas`/`sitekw` 里的预筛难度是快照口径，只用于海选砍量，结论以 `kd` 为准。
- 品牌词会切换口径（出现两个分数）：主分数回答「第三方以衍生内容进入有多难」。
- 外链预算：按 Ahrefs KD→引用域曲线插值，是量级参考；页面同时给「盘面前十最弱占位者」作为现实对照。

## 搜索量（`kd` 的 kwstats / `ideas` / `sitekw` / `trends`）

- `kd` 的月搜索量来自排名站点主力流量词，是估算；`ideas`/`sitekw` 用快照库。
- `trends` 的 0–100 是相对热度，**不是搜索量**；判新词以 12 个月或 5 年窗口为准。
- 同一关键词在不同工具里数字不同是正常的（口径/时间不同），不要混着算。

## 流量与 DR

- 月访问量是 SimilarWeb 口径的估算值，不是真实营收；估值工具也会这样标注。
- DR 来自 Ahrefs；无数据的域名按 0 看，不代表真的 0；缓存 30 天。
- `sitekw` 的「估算月搜索流量」只算自然搜索。

## SERP 盘面（`serp`）

- 逐页体检的 On Page 分数与 `audit` 同引擎，但 SERP 页面只做快速体检（部分指标）。
- 「最薄弱占位」是超越目标建议，不是保证能超。

## 页面体检（`audit` / `review`）

- `audit` 分数是 On Page 自查分，不等于排名；关键词聚焦度不足会把总分封顶。
- `review` 的 P0/P1/P2 按性价比排序；推断词不是用户给的词时，先说明再给建议。

## 估值与外链（`worth` / `backlink`）

- 估值是模型区间（含月收入估算），不是成交价；模型选错（AI 站 vs 广告内容站）差异很大。
- 外链结论基于同档挂牌价样本；样本少的站置信度低。

## 趋势（`trends`）

- 「是不是新词」「处在什么时期」「适不适合上站」是页面规则判断，只看曲线形状，不看搜索量与竞争；与站点规划冲突时以规划为准（页面会注明）。

## 域名（`history` / `bulk` / `dr`）

- 存档快照只代表 Archive 抓到过的内容；没抓到不等于没用过。
- whois 注册时间与「换过主人」无关，改版史看内容对比。
- `bulk` 的注册状态来自 `query.domains`，实时性以页面为准。

## Agent（`chat`）

- Agent 回答是「大模型 + 工具结果」的综合，引用它的结论时要能追到工具数据；它有时会给出衍生建议，注意区分「数据」与「推断」。
- 每条消息与工具调用都计费，追问越多越贵。

## 变现计算器（`money` / `cashflow` / `influencer` / `kgr`）

- 都是**线性模型**：输入假设决定输出。引用结论时必须带上关键假设（点击收益、回款比例、衰减率、外链单价等）。
- `kgr` 的三个输入是自填值，数字质量取决于用户提供的 intitle/搜索量/KD 口径。
